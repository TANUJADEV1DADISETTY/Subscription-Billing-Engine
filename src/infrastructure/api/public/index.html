🏛️ Architectural Guarantees & Verification

  • Single Responsibility Principle (SRP): Domain rules (discount, expiration logic) are completely separated from HTTP, DB, and Payment APIs.
  • Dependency Inversion Principle (DIP): SubscriptionBillingService depends only on abstract Ports (ISubscriptionRepository, IPaymentGateway, ITimeProvider).
  • Temporal Decoupling: Deterministic time injected via ITimeProvider; no direct new Date() calls inside the core domain.
  • Isolated Unit Testing: 100% code coverage achieved without requiring running databases or internet connections.
